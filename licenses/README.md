# Font licenses

Copyright notices are inside each font file. This directory holds the license texts those files point at.

| License file | Faces |
| --- | --- |
| [OFL-1.1.txt](OFL-1.1.txt) | The SIL Open Font License faces, including Noto, Liberation, Inter, Source, IBM Plex, Carlito, Caladea, EB Garamond, the other Google faces, Cascadia Code, Cascadia Mono, Selawik, Fira Code, Fira Mono, JetBrainsMono Nerd Font Mono, and the extra coding faces in `fonts-coding/` |
| [Ubuntu-Font-Licence-1.0.txt](Ubuntu-Font-Licence-1.0.txt) | Ubuntu, Ubuntu Condensed, Ubuntu Mono, Ubuntu Sans, Ubuntu Sans Mono |
| [GUST-FONT-LICENSE.txt](GUST-FONT-LICENSE.txt) | TeX Gyre |
| [Gillius-GPL-2.0.txt](Gillius-GPL-2.0.txt) and [Gillius-font-exception.txt](Gillius-font-exception.txt) | Gillius ADF No2 |
| [DejaVu-LICENSE.txt](DejaVu-LICENSE.txt) | DejaVu Sans, DejaVu Serif, DejaVu Sans Mono |
| [Hack-LICENSE.md](Hack-LICENSE.md) | Hack (MIT, plus the DejaVu and Bitstream Vera terms) |
| [NerdFonts-Symbols-MIT.txt](NerdFonts-Symbols-MIT.txt) | Symbols Nerd Font |
| [AGPL-3.0.txt](AGPL-3.0.txt) and [URW-AGPL-font-exception.txt](URW-AGPL-font-exception.txt) | D050000L and Standard Symbols PS |

`ms-fonts/` and `fonts/microsoft/` are not in this repository. Those files are covered by a Windows or Microsoft 365 license, or by the core fonts EULA when a distro package or `./install.sh --download` fetches the classic set.
